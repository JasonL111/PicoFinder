# V1.2 Motion & UI Polish

## 信息层级

设备列表保留前台扫描、权限入口和 Debug 演示，使用稳定 Device ID 作为卡片 key，沿用
设备库顺序；RSSI 更新不排序，也不重播入场。卡片显示名称、状态、末次 RSSI 与进入提示。

查找页依次显示标签名称 / ID、信号主视觉、设备概况、设置入口、可展开的信号详情、
扫描控制和估距说明。主视觉突出等级和靠近 / 远离 / 稳定的趋势图标与文字；没有方位箭头。
概况保留粗略米数、在线状态与最后收到广播时间；详情保留原始 / 平滑 RSSI、1 米参考、
环境系数、电量和协议。折叠只降低技术信息的视觉权重，不删除数据或操作。

设置页首先显示极近振动开关，随后是原有名称、n、1 米参考、失联超时、保存、校准及
删除确认。开关立即保存；其余输入仍由原 ViewModel 校验和保存。没有极强 RSSI 编辑器。
页头始终标记 V1.2，列表底部与设置“关于”显示当前安装构建版本 / versionCode。
各页面独立 LazyColumn，进入查找 / 设置时从顶部开始，不继承上一页的滚动位置。
Android 返回键和顶部返回按钮使用原导航边界；退出查找的会话清理立即执行，不等待淡出。

## 设计参数

| 元素 | 参数 |
|---|---|
| 主题 | 系统深 / 浅色，青绿主色，低饱和平面背景，无大面积渐变 |
| 页面边距 / 卡片圆角 | 20 dp / 24 dp |
| 主视觉圆环 | 最大 248 dp，随小屏可用宽度缩小 |
| 排版 | 标题 24–32 sp，正文 14–16 sp，辅助 12 sp；随系统字体缩放 |
| 信号进度 / 颜色 / 光晕 | 450 ms，有终点的过渡 |
| 等级与趋势文字 | 220 ms 淡入、120 ms 淡出 |
| 页面 | 240 ms 淡入 + 小幅垂直位移、140 ms 淡出 |
| 技术详情 | 220 ms 展开、180 ms 收起；关闭动画时直接显示 / 隐藏 |

信号和状态使用 Compose `animateFloatAsState`、`animateColorAsState`、`AnimatedContent`、
`AnimatedVisibility`。进度采用 `FastOutSlowInEasing`，列表状态通过原生 `Text.minLines`
预留行数、适配字体缩放和换行，减少
文字长短变化引起的布局移动。使用 Material 3 原生按钮、Switch、Card、输入框与按压反馈，
没有新增第三方生产 UI 依赖。

## 动画与测量的边界

圆环沿用 V1.1 相对进度映射（平滑 RSSI 的 -100 至 -35 dBm 映射到 0–1），只将显示
目标取整到 2% 小台阶，避免微小噪声抖动。这不是距离区间、检测阈值或新的滤波算法。
原始和平滑 RSSI、估算米数、校准输入始终来自原数据，绘制中间值不写回业务层。
原有约每秒 UI 数值刷新保持不变，BLE 回调不创建动画，不调整扫描频率。

非常强仅使用已有 `veryStrongSignal` 确认状态，加上扫描中 / 当前设备仍有实时信号的
展示约束。确认后光晕透明度一次过渡到 0.12，随后静止；退出后淡出。不会用一次原始
峰值、圆环填满、估算距离或手机方向代替稳定确认，更不会从动画请求振动。
V1.1 固定 -45 / -51 dBm、稳定样本、单次锁和冷却规则，以及 Fake 禁止真实触感的策略均未改动。

普通扫描只在开始 / 停止时有限淡入并改变图标颜色，没有无限旋转、循环呼吸、声音或
额外振动。失联 / 停止后圆环过渡到零和中性色，不继续强调旧信号；最后广播信息仍可查。
这些是有限视觉变化，稳定状态不主动驱动帧循环。

## 生命周期与无障碍

视觉层监听宿主 Lifecycle 和系统 `ANIMATOR_DURATION_SCALE`，后台或动画比例为零时，
进度 / 颜色直接展示目标值，页面和状态不做尺寸 / 淡入动画；返回前台重新读取设置。
不修改 Activity 原有后台停止扫描、手动重启与最长 2 分钟限制。

等级和趋势均有文字，图标不承担唯一含义。圆环无障碍描述包含“相对蓝牙信号强度”和
等级，进度语义使用测量目标而非逐帧插值，避免每帧播报。返回、开关和详情等使用系统
可点击组件；权限按钮可换行，内容可滚动，支持大字体。字体和低动画设置不改变测量或触感。

## 验证与截图

自动化分为纯 JVM 业务回归、真实 Activity + Fake Scanner 交互，以及受控 DeviceState
的 Compose 渲染。后者明确显示“受控模拟数据”，验证深浅主题和 1.8 倍字体，不代表
真实射频、实际马达或手机帧率。测试中的动画时钟可控，不使用真实等待模拟信号稳定。

实际命令、结果和截图位置记录在 [testing.md](testing.md)。本环境没有物理手机 / Pico，
需要用户在自己的设备检查顺滑程度、字体、系统减少动画设置和 V1.1 近距离短振；
没有实测耗电 / 帧耗时数据，不能宣称所有厂商设备都达到特定帧率或功耗。
